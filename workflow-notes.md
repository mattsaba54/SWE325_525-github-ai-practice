# GitHub Workflow Notes

Feature branch: feature/github-ai-workflow

## GitHub Workflow

An issue is used to describe the work that needs to be completed and helps keep track of the tasks for the project.

A branch lets me work on changes separately without changing the default branch right away. For this lab, I am using the feature/github-ai-workflow branch.

A commit saves a specific set of changes to the repository and creates a record of what was changed.

A pull request is used to propose the changes from my feature branch and review them before they are merged into the default branch.

The default branch for this repository is main. After the changes are reviewed and approved, they can be merged into main.
